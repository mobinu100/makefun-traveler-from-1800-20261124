# One Sentence for a Traveler from 1800

Entry for [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) on make.fun.

The program writes one sentence to `/output/entry.txt` — a single picture an 1800 traveler can hold: the post office that never sleeps.

> It is a post office that never sleeps, where a letter sent from London reaches Canton before your tea grows cold, and the answer comes back the same way.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final sentence (a constant, 153 characters, one sentence) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
